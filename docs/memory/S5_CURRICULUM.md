# S5 直線坐標幾何教材來源

## 摘要

S5 課程整理自 `S5_book_photo/IMG_4649.jpeg` 至 `IMG_4668.jpeg`。原始圖片不進入 Git；MarkItDown Vision 轉換結果在 `content/s5/ocr/`，整理後的網站資料在 `src/data/s5Curriculum.ts` 與 `src/data/s5Questions.ts`。

## 照片與課程對照

| 原圖 | 主要內容 | S5 單元 |
|------|----------|---------|
| IMG_4649 - IMG_4650 | 有向線段、兩點距離、定比分點 | `s5-directed-segment`、`s5-section-point` |
| IMG_4651 - IMG_4654 | 定比分點、重心、三角形與多邊形面積 | `s5-section-point`、`s5-polygon-area` |
| IMG_4655 - IMG_4656 | 傾斜角、斜率、三點共線 | `s5-slope` |
| IMG_4657 - IMG_4658 | 點斜式、斜截式、兩點式、截距式、一般式 | `s5-line-forms` |
| IMG_4659 - IMG_4660 | 兩線夾角、平行／相交／垂直／重合 | `s5-line-relations` |
| IMG_4661 - IMG_4662 | 點、直線對稱；點到直線距離與平行線距離 | `s5-distance-normal` |
| IMG_4663 - IMG_4664 | 法線式與直線系 | `s5-distance-normal`、`s5-line-family` |
| IMG_4665 - IMG_4668 | 直線練習與綜合應用 | 各 S5 練習主題 |

## 整理規則

- OCR 只作為可追蹤的來源稿，不直接當作網站資料。
- 公式、題目選項與答案均經人工校正；無法可靠辨識的內容不臆造。
- 網站仍遵守台灣教材與現有繁體中文用語，不新增視覺主題。
