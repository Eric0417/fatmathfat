# 集合好好學實作狀態

## 摘要

本版已在原有學習體驗上完成全棧學校版本：FastAPI + PostgreSQL 後端、Email OTP 登入、學生／管理員角色、學習數據同步、管理員後台與 DeepSeek AI 老師。網站需連線；舊版 `localStorage` 資料保留但不遷移。

## 核心功能狀態

|------|------|------|

## 離線與連線

**狀態：網站需連線**

- 第一次在網路環境載入後，Workbox 預先快取 HTML、JS、CSS、圖示與 manifest。
- 未登入或離線時顯示登入頁；登入、學習數據與 AI 都需要 API 可用。
- 已使用 production preview 驗證：離線重新載入不會繞過登入頁。

## 既有邊界

- Render 資料庫或服務停機時，網站無法登入或同步；需配置錯誤提示與重試。
- 描述法的論域目前以自然語言與有限整數呈現，尚未建立獨立的 domain 資料模型。
- 不會加入作業派發、即時在線狀態、AI 對話審查、AI 題目入庫或複雜動畫。
